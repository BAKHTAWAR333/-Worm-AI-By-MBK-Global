Help Center

Frequently Asked Questions.

Quick answers about Worm AI features, usage, and API behavior.

ASK AWAY
FAQ

A few useful answers.

Everything you need to know before you start using Worm AI.

12 ANSWERS
01What is Worm AI?

Worm AI is the chat workspace connected to the Worm API. You can ask questions, request writing help, choose a response mood and send images for analysis.

02Can I continue the same conversation?

Yes. The workspace keeps the API chat ID during the current session and sends it with later messages when the API provides one.

03Can I ask in Urdu?

Yes. You can type Urdu directly or use the Urdu quick prompt. The response language ultimately depends on what the connected AI API returns.

04Can I send an image?

Yes. Use the paperclip button or Vision page, select an image and send your question. The image is converted to a data URL and included in the chat request.

05How does voice playback work?

If the API returns a speech URL, Worm AI adds a Listen button to that response. If no audio URL is available, the response remains text-only.

06What is MBK Global?

MBK Global is the community development group behind Worm AI. We build 25+ free web tools including movie finders, text writers, medicine price checkers, and more.

07Can I request a custom website?

Yes! Visit the "Request Website" section, fill the form, and we'll reply on WhatsApp with a quote and timeline. Free and paid options available.

08What if the API fails?

Try again first. If the issue continues, check whether the API endpoint is reachable and whether its response format is available. The workspace also shows a request-failed notification.

09Is my chat history saved?

Yes. Your last 20 conversations are saved locally in your browser under the History section. You can clear them anytime. Nothing is sent to our servers except the chat API request itself.

10Does Worm AI work offline?

No — the AI chat requires an active internet connection to reach the Worm API. However, the interface itself loads instantly and works on any modern browser.

11How do I open the menu?

On mobile, tap the menu icon on the right side of the top navigation. It changes to a close icon while the navigation drawer is open.

12Can I share this website?

Absolutely. Click the share icon in the top bar to share via WhatsApp, Twitter, Facebook, Telegram, or copy the link. Spread the word!
